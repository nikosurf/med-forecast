Synchronisation

Sans réglage, tes reports restent sur ce téléphone. Avec un jeton GitHub, ils sont aussi enregistrés dans ton dépôt, et le bouton « Mettre à jour » relance la collecte.

Pour créer le jeton, sur github.com :
  1. Photo de profil, Settings, Developer settings, Personal access tokens, Fine-grained tokens, Generate new token.
  2. Repository access : Only select repositories, med-forecast.
  3. Permissions : Contents en Read and write, Actions en Read and write.
  4. Expiration : 1 an, puis Generate token et colle-le ici.
Le jeton reste sur ce téléphone, il n'est jamais publié.
